CET-6 听力系统 · 使用说明
==========================

一、启动（两步）
  1. 双击本目录的 启动.bat
     启动服务(8123，HTTPS) → 打开浏览器
  2. 服务启动后会自动把 TTS 和发音评分模型加载到 GPU（后台约 1 分钟），
     预热完成前首次生成/评分会稍慢，属正常

一.5、手机同网访问（可选）
  1. 电脑和手机连同一个 WiFi
  2. 双击 启动.bat，脚本会在窗口里打印手机访问地址，例如：
        https://10.68.212.78:8123
  3. 手机浏览器打开该地址：
     - 首次访问会提示「证书不受信任」：点「高级 / 继续前往」即可（这是本机自签名证书，正常）
     - 麦克风（口语练习录音）必须在 HTTPS 下才能用，所以要用 https:// 而不是 http://
  4. 页面已做移动端适配：Tab 可左右滑动、按钮加大触控区、逐词点击同样可用
  5. 若要防止局域网内他人访问：在 config.toml 的 [server] 里把 access_token 填一个口令，
     之后手机首次打开会要求输入该令牌

二、功能模块

【模型切换】（页面顶部）
  · 生成模型：云端 DeepSeek（本地 Qwen 已停用，显存留给 TTS/评分模型）
  · 顶部可填 DeepSeek API key（保存在 deepseek_key.txt），云端模型下拉可选
  · 状态点绿色=在线，灰色=离线

【逐句翻译】（两个功能通用）
  · 互动故事：每句话、每个 A/B/C 选项右侧都有「译」按钮
  · 每日一篇：每句对话/旁白右侧都有「译」按钮
  · 点一下在原句下方展开中文译文，再点收起；同句重复查看不重复请求（已缓存）
  · 翻译用当前激活的生成模型，不额外消耗资源

【翻译写作】（第三个 Tab，练输出能力）
  · 顶部「写作 / 翻译」切换
  · 写作：出一题（议论三三类/应用文/图画/图表六类题库）→ 写作文 → 批改（分数+范文+逐段批注）
  · 翻译：出一题（汉译英材料，文化/社会/科技三题材）→ 译英文 → 批改（参考译文+逐句点评+分数）
  · 翻译两种模式（顶部切换）：
    整段模式：整段译 → 整段批改（保持原有体验）
    单句模式：材料拆成单句，每句一个输入框 +「参考译文」按钮 +「提交批改」按钮（逐句打分点评）
  · 分数按六级标准满分 15 分，分档 14/11/8/5/2
  · 题型题库内置，话题由 AI 现场编，不固定

【互动故事】（主形态，练听力玩剧情）
  · 点「开始新故事」→ AI 生成开场段，逐句朗读（边生成边读）
  · 句子下方出现 A/B/C 三个走向选项，选一个推进剧情
  · 或直接在 D 输入框自己写走向（中文英文都行，故事永远是英文）
  · 每段默认织入当天六级词（25 个采样词，与每日一篇同步，无开关）
  · 正文里每个单词都可点击：弹「播放」/「＋收录」气泡，收录进笔记本
  · 听完随时点「存档结束」→ 整局拼接成音频存进互动故事文件夹

【笔记本】（生词/句式/表达 三合一）
  · 入口：顶部「笔记本」Tab，内分 生词 / 翻译句式 / 写作表达 三类
  · 收录来源：
    生词：互动故事正文点单词 → 「＋收录」（释义自动填，词表没有的用 AI 翻译）
    翻译句式：翻译练习每句旁「收录」（中文原句+参考译文，可勾选 AI 句式解读，可改内容）
    写作表达：写作批改的范文按段拆分，每段旁「收录」
  · 功能：编辑 / 删除 / 导出 txt / 复习模式（看正面想反面）/ 播放发音
  · 重复收录自动去重
  · 数据保存在 系统\笔记本.json（本机，不入库）

【每日一篇】（辅形态，贴词汇表）
  · 点「生成今日一篇」→ 约 1-2 分钟生成+朗读+归档
  · 题型按天轮换：长对话 → 短文 → 讲座（循环）
  · 每篇织入当天词块采样（60 个目标词，通常命中 50+）
  · 词汇来自 单词\wordlist_cet6_乱序.txt，按 300 词/天推进，循环覆盖

【口语练习】（练发音，音素级评分）
  · 点「生成朗读题」→ AI 出约 100 词英文短文（织入 20 个六级词）+ Kokoro 范本朗读
  · 点「开始朗读」→ 浏览器录音（最长 60 秒）→「停止并评分」
  · 评分：OpenPronounce（wav2vec2 + DTW，本地离线），给出 0-100 总分 + 逐词着色
    （绿=读对，红=待改进）+ 具体音素错误（如 /æ/ → /eɪ/）+ 练习建议
  · 首次评分需下载两个 wav2vec2 模型（约 1.2GB×2，走 hf-mirror），之后离线且更快
  · 建议戴耳机在安静环境朗读；历史可回放你的录音与范本

三、文件归档
  每日一篇：CET-6\每日一篇\YYYY-MM-DD\
    story.wav / story.mp3   音频（PotPlayer 可变速播放+字幕）
    story.srt               句级字幕（PotPlayer 自动加载同名 srt）
    story.txt               原文+题型标注
    words.txt               本篇实际命中的词汇清单
  互动故事：CET-6\互动故事\YYYY-MM-DD_session-NN\
    story.wav / story.mp3   整局拼接音频（回听）
    transcript.txt          完整剧情 + 你的每次选择
  口语练习：CET-6\系统\历史记录\speaking\<时间戳_id>\
    content.json            朗读文本 + 评分结果（总分/逐词/音素错误）
    ref.mp3                 范本朗读
    user.mp3                你的录音（回听）

四、配置（系统\config.toml）
  · [llm] active: cloud=云端 DeepSeek（默认，需填 API key）
  · [tts] voice_main / voice_male: 女声/男声音色（Kokoro 美音音色表见下）
  · [daily] chunk_size/sample_n: 每日词块大小 / 每篇织入词数
  · [speaking] passage_words/sample_n/max_record_sec/scorer: 口语朗读题词数/织入词数/最长录音秒数/评测引擎
  · [server] port: 服务端口

  常用美音音色：af_heart(温柔女声,默认) af_bella(甜美) af_nicole(成熟)
                am_michael(男声,默认) am_onyx(低沉男声)

五、已知注意
  · 启动后 TTS/评分模型自动预热到 GPU（约 1 分钟），预热期间生成/评分会排队等待
  · 互动会话存内存，重启服务后旧会话无法继续（但已存档的音频不受影响）
  · 词表覆盖 3991 个去重词，约 14 天一轮（300/天）
  · 生成走云端 DeepSeek，需保持网络通畅且 key 有效

六、停止
  任务管理器结束 python 进程，或 Ctrl+C 关闭服务窗口。
